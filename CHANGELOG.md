# Changelog

## Initial public preview — 2026-10-09

- Local English transcription, transcript-based highlight selection and supported URL/local-file input.
- Animated caption styles, quality MP4 exports, original sound accents and sparse bubbles/stickers.
- Stable prominent-face framing with a dead zone, sustained-movement threshold and bounded easing.
- Editable title, description, hashtags and tags with text/JSON downloads.
- CPU/GPU startup checks, tested encoder selection and first-run Windows dependency setup.
- Transcript corrections, manual ranges, pause/filler cuts, local presets, feedback and ZIP downloads.

Seven local regression tests and sample renders passed. Fresh Windows installation, live interface validation for the latest update and GitHub Actions remain unverified. This is a public preview, not a promise of viral results.
